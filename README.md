# 📐 Geometry Construction Tool for JHS Students

An interactive web-based learning tool designed to help Junior High School students explore and understand geometric concepts through hands-on interaction.

## 🎯 Features

### 1. **Angle Types** 📏
- Interactive angle slider (0° - 360°)
- Real-time visualization of angle types:
  - **Acute Angles** (0° - 90°)
  - **Right Angles** (90°)
  - **Obtuse Angles** (90° - 180°)
  - **Straight Angles** (180°)
  - **Reflex Angles** (180° - 360°)
  - **Full Rotation** (360°)
- Visual arc representation showing the angle
- Quick access cards to jump to specific angle types

### 2. **Perpendicular Lines** ⊥
- Interactive tool for constructing perpendicular lines
- Click-to-place points on the base line
- Automatic construction of 90° angle
- Right angle symbol indicator
- Visual demonstration of perpendicular properties

### 3. **Parallel Lines** ∥
- Visual representation of parallel lines
- Add multiple parallel lines incrementally
- Show equal distance measurements between lines
- Understand the "never intersecting" property

### 4. **Free Construction Tool** 🛠️
- **Draw Lines**: Connect any two points
- **Draw Circles**: Define center and radius
- **Mark Angles**: Place angle markers anywhere
- Grid background for reference
- Clear and reset functionality

### 5. **Interactive Quiz** ✓
- 5 progressive questions covering all concepts
- Immediate feedback on answers
- Score tracking
- Visual progress indicator
- Results summary with performance rating

## 🚀 Getting Started

### Installation
1. Clone the repository:
```bash
git clone https://github.com/emma-boamah/construction_for_jhs.git
cd construction_for_jhs
```

2. Open in browser:
```bash
# Simply open index.html in your web browser
# No build process or dependencies required!
open index.html
```

You can also deploy to GitHub Pages for live access:

2. Set source to `main` branch
3. Access via `https://emma-boamah.github.io/construction_for_jhs`

## 📚 How to Use

### For Students:
1. **Start with Angles**: Use the slider to see how angles change
2. **Click Angle Cards**: Jump to specific angle types to understand their properties
3. **Explore Perpendicular Lines**: Click on the base line to construct perpendiculars
4. **Add Parallel Lines**: Build intuition about parallel lines and equal spacing
5. **Create Your Own**: Use the construction tool to combine all concepts
6. **Test Knowledge**: Take the quiz to assess understanding

### For Educators:
1. Use in classroom with projector for group learning
2. Assign specific concepts for homework
3. Use quiz results to identify learning gaps
4. Embed in learning management systems via iframe
